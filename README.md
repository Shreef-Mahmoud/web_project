# ⚽ Football T-Shirts Store

A web application for browsing and purchasing football t-shirts, built as a summer training project by 5 students from the Faculty of Computer & Information Sciences, Ain Shams University.

## 📖 About

Inspired by a love for football and the excitement of new kit releases each season, this project is an e-commerce style store for football t-shirts. It supports both a customer-facing shop and an admin side for managing products and users.

## ✨ Features

- **Home & Shop pages** — browse the latest t-shirts with search and pagination
- **User authentication** — sign up and log in
- **About page** — team and contact information
- **Admin tools**:
  - Add new products (name, description, price, color, size, quality, photo)
  - View all products
  - View all registered users

## 🗂️ Project Structure

```
├── Home.html            # Landing page
├── Shop.html             # Product catalog with search & pagination
├── about.html             # About the team / contact info
├── login.html              # User sign-in
├── signup.html              # User registration
├── Addproduct.html           # Admin: add a new product
├── displayproducts.html       # Admin: view all products
├── displayusers.html           # Admin: view all users
├── cssfiles/                    # Stylesheets
├── jsfiles/                      # Application logic (logic.js, home.js)
└── images/                        # Logo and background assets
```

## 🛠️ Tech Stack

- HTML5 / CSS3
- Vanilla JavaScript

## 🚀 Getting Started

1. Clone the repository:
